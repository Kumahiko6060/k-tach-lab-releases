## インストール
1. QR を読み取り、APK をダウンロード
2. ダウンロード完了の通知、またはファイルアプリから APK を開く
3. 初回のみ「この提供元のアプリを許可」をオンにする
4. 「インストール」(Play プロテクトの警告が出たら「インストールする」)
